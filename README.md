# 🌐 Web Security Lab

## 📌 About

This repository documents my hands-on learning in Web Application Security and Vulnerability Assessment.

The practical work is performed only in authorized and intentionally vulnerable lab environments.

## 🎯 Objectives

- Understand how web applications work
- Learn HTTP and HTTPS
- Understand authentication and authorization
- Practice using Burp Suite
- Learn OWASP Top 10
- Identify common web security vulnerabilities
- Learn vulnerability assessment and reporting
