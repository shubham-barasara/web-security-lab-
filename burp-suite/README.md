# 🛡️ Burp Suite

## 📌 About

Burp Suite is a web application security testing platform used to analyze and test HTTP/HTTPS traffic.

I am learning Burp Suite for authorized web security labs and VAPT practice.

## 🔧 Main Components

### Proxy

Used to intercept and inspect HTTP/HTTPS requests and responses.

### Repeater

Used to manually modify and resend requests during authorized security testing.

### Intruder

Used for automated request testing in controlled lab environments.

### Decoder

Used to encode and decode data formats.

### HTTP History

Used to review previously captured HTTP requests and responses.
