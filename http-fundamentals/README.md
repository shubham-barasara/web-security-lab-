# HTTP Fundamentals

## What is HTTP?

HTTP (HyperText Transfer Protocol) is the protocol used for communication between a web browser and a web server.

## Important HTTP Methods

- GET - Retrieve data
- POST - Send data
- PUT - Update data
- DELETE - Delete data

## Common HTTP Status Codes

- 200 - OK
- 301 - Redirect
- 302 - Temporary Redirect
- 400 - Bad Request
- 401 - Unauthorized
- 403 - Forbidden
- 404 - Not Found
- 500 - Internal Server Error

## Security Relevance

Understanding HTTP requests and responses is essential for web application security testing and VAPT.
