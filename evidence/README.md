# VAPT Evidence

This directory contains sanitized evidence collected during authorized security testing in intentionally vulnerable laboratory environments.

## Evidence Structure

Each finding should have its own evidence directory.

Example:

```text
evidence/
├── VAPT-001/
│   ├── README.md
│   ├── request.txt
│   ├── response.txt
│   └── screenshot.png
│
├── VAPT-002/
│   ├── README.md
│   └── screenshot.png
│
└── VAPT-003/
    ├── README.md
    └── screenshot.png
