# 🛡️ OWASP Top 10

## 📌 About

The OWASP Top 10 is a widely used awareness document describing important web application security risks.

I am studying these vulnerabilities through authorized and intentionally vulnerable security labs.

## 🔎 Topics

### 1. Broken Access Control

Learning how improper authorization can allow users to access resources they should not be able to access.

### 2. Cryptographic Failures

Learning about weaknesses related to protecting sensitive data and cryptographic practices.

### 3. Injection

Learning how unsafe handling of user input can lead to unintended commands or queries.

### 4. Insecure Design

Understanding security weaknesses caused by missing or insufficient security controls in application design.

### 5. Security Misconfiguration

Learning how incorrect or insecure application and server configurations can create security risks.

### 6. Vulnerable and Outdated Components

Understanding the risks of using outdated or vulnerable software components.

### 7. Identification and Authentication Failures

Learning about weaknesses in authentication and session management.

### 8. Software and Data Integrity Failures

Understanding risks related to untrusted software, updates, and data integrity.

### 9. Security Logging and Monitoring Failures

Learning why proper logging and monitoring are important for detecting security incidents.

### 10. Server-Side Request Forgery (SSRF)

Learning the security concepts behind applications making unintended requests to internal or external resources.
